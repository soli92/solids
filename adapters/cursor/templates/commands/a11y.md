# Comando: /a11y

> Equivalente Cursor del comando Claude Code `/a11y` (`.claude/commands/a11y.md`).
> EP-007, opt-in `a11y.enabled`.

**Sintassi**:
```
/a11y <target> [--standard=wcag22aa] [--include-interactive] [--ephemeral]
```

> **Gate**: `factory.config.yaml.a11y.enabled: true`. Se `false` → ABORT pulito.

## `<target>` — 4 forme

| Forma | Esempio | Significato |
|---|---|---|
| **URL** | `/a11y https://app.example.com/checkout` | route live (Playwright+axe) |
| **path file** | `/a11y src/components/Button.tsx` | file componente isolato |
| **dir di build** | `/a11y dist/` | output statico/SSR |
| **TSK-id** | `/a11y TSK-039` | ricava target dal frontmatter TSK |

## Flag

- `--standard=wcag22aa` — default `wcag22aa` (tag axe-core).
- `--include-interactive` — default `false`. Abilita check tastiera/focus/reflow (richiede Playwright).
- `--ephemeral` — nessuna scrittura in `code_quality/reports/` (solo chat + log).

## Comportamento

1. Verifica `a11y.enabled: true`.
2. Risolvi target. Con TSK-id: glob `management/kanban/**/TSK-<id>.md`.
3. Invocazione con fallback: agente `a11y-specialist` (se scaffoldato e `a11y.agent: true`) → skill `accessibility-testing-protocol` via `fe-dev`/`qa-dev` → fail-loud.
4. Report con schema standard: `{target, standard, summary, automated_findings, manual_checks, positive_findings}`. `manual_checks` mai vuota (N ≥ 1) — regola di neutralita'.
5. Su TSK-id: aggiorna solo `a11y_status:` nel frontmatter TSK.

## Storage

- Con TSK-id: `code_quality/reports/<TSK-id>-a11y-iter-<N>.{json,md}`
- Standalone: `code_quality/reports/_adhoc/a11y-<YYYY-MM-DD-HH-MM>-<slug>.{json,md}`
- `--ephemeral`: nessuna scrittura

## Vincoli

- **Mai dichiarare conformita' WCAG/legale**: pre-screening interno, non audit ufficiale.
- L'agente non modifica il corpo dei TSK: solo `a11y_status:`.

## Limitazioni Cursor

- Playwright deve essere installato per check interattivi (terminal Cursor).
- Usare `npx axe-cli <url>` come alternativa rapida per check automatici di base.
