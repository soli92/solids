# US-002 — Token M3 Expressive additivi

Come consumer di SoliDS voglio i token di Material 3 Expressive (spaziatura, breakpoint, scala dei
raggi, motion a molle, target 48dp) per costruire UI allineate a M3 senza che cambi nulla di cio'
che gia' uso.

## Criteri di accettazione

| AC | Criterio | Verifica |
|---|---|---|
| AC1 | Nessun token esistente cambia nome o valore | diff di `dist/css/variables.css` e `themes.css` prima/dopo: solo righe aggiunte |
| AC2 | Scala di spaziatura M3 `space0..space900` esposta con i valori ufficiali | `tokens-sanity` |
| AC3 | Breakpoint M3 (600/840/1200/1600) esposti come token e come varianti Tailwind v4 | `tokens-sanity` + build Storybook |
| AC4 | Scala corner M3 a 10 gradi, valori ufficiali in light/dark, declinata per ogni tema e monotona | `tokens-sanity` |
| AC5 | Motion a molle: 12 curve ufficiali per il web, schema expressive di default e standard via `data-motion` | `tokens-sanity` |
| AC6 | Documentazione Storybook foundations aggiornata | lettura |
| AC7 | `npm test` verde (build, tokens-sanity, build-storybook) | comando |

## Decisioni aperte (maintainer)

Cambi che allineerebbero i default a M3 ma sono **breaking** per i consumer (major 3.0.0):

1. `--sd-radius-2xl` / `--sd-radius-3xl` da 20/24px ai valori M3 28/32px;
2. `--sd-layout-touch-target-min` da 44px (Apple HIG) a 48px (M3);
3. `.sd-transition*` dalle curve durata+easing alle molle M3 (cambia la sensazione di ogni transizione).
